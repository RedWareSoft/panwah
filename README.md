# Panwah
Experimental linux distribution

# Requisites:
* CPU: Only INTEL x86 64 bit
* GPU: INTEL integrated graphics card, no tested with AMD APU's and no recommended with NVidia cards
* RAM: 2 GB
* Storage: 8 GB
* Sound card: HDA Intel PCH

## Supported machines:
| CPU 			| GPU				| Sound card		| Audio codec chip	| Machine			|
| -			| -				| -			| -			| -				|
| Any INTEL x86_64	| Any integrated INTEL GPU	| HDA Intel PCH		| ALSA compatible	| Generic Desktop/Laptop	|
| Intel	Core i5-2410	| Intel 2nd GEN			| HDA Intel PCH		| IDT 92HD87B1/3	| Hewlet-Pakard	ProBook 4430s	|
